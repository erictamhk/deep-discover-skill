# 古埃及人到底怎麼建造吉薩大金字塔的？

## 我們實際上知道什麼？

### 摘要

要回答這個問題，必須把「我們**確定**知道的」與「仍然**爭議／未知**的」分開。對吉薩大金字塔的建造，目前學界的共識是：

- **我們確知**：建材的運輸（尤其是從採石場到吉薩、跨越尼羅河的水路運輸）規模龐大且有直接文獻與考古證據；建造者是一支大型、伙食良好、以義務勞役（corvée）組織起來的埃及工人隊伍，**不是**奴隸；金字塔的規模數字（約230萬塊、平均每塊2.5噸、高約146.6公尺）大致被接受。
- **我們不知／仍在爭議**：石塊究竟如何被「**抬升到高度**」。沒有任何來自胡夫時代的文獻說明建造技術，多種斜坡（ramp）理論與非斜坡理論（滑輪配重、水力升降）彼此競爭，但**沒有一個被證實**。這是問題的真正核心，也是誠實的答案：**目前仍無定論**。

---

### 一、建造方法（如何移動與抬升石塊）— 核心爭議，無定論

- 沒有發現任何胡夫（Khufu）時代的文獻說明金字塔是如何建造的；現代埃及學者與希羅多德問的是同一個問題（EV-0002, EV-0008）。
- **斜坡+槓桿** 是「最站得住腳」的方法家族，但學者自己也承認它「不完整、必須輔以其他裝置」。考古紀錄只留下小型斜坡與斜道，**沒有足以建造大部分建築的巨大斜坡遺跡**（EV-0001）。
- 外部直坡理論的硬傷：要抬升到頂，斜坡需約為金字塔高度的10倍長（約1.5公里），體積可能數倍於金字塔本身，且吉薩平原空間不足；**無此類斜坡的考古遺跡**（EV-0003）。
- 螺旋斜坡（外部或內部，如 Houdin 的內部螺旋坡理論）有其缺點：單列運輸、約20個轉角導致堵車、遮蔽測量線。Houdin 理論**未被證實**，並被埃及學者批評為「牽強而複雜」；牛津的 John Baines 也「懷疑任何只解釋大金字塔的理論」（EV-0004, EV-0005）。
- 因此結論是：**現代埃及學者多半同意，大金字塔的建造方法「尚待解開」**（EV-0002）。

### 二、考古證據到底說了些什麼

- **Merer 日記（Wadi al-Jarf / 紅海卷軸）**：2013 年由 Pierre Tallet 發現，是世界上最古老的紙莎草文獻之一。Inspector Merer 記錄他的團隊把圖拉（Tura）石灰岩用船運到吉薩，用於外層覆面（EV-0007, EV-0008）。
  - **關鍵限制**：Merer 日記**沒有提到任何建造／抬升技術**，只記錄了河道運輸（EV-0008）。
- **2024 年消失的「阿赫拉馬特」尼羅河支流（Ahramat Branch）**：以雷達衛星影像與沉積物岩心，測繪出一條約64公里、200–700公尺寬的失落河段，沿著金字塔帶分布，許多金字塔的堤道通向它；被認為是運輸水道（EV-0009）。
- **吉薩水港與「胡夫湖」**：考古發掘（船坑、600英尺防波堤、130個錨、人工盆地/水道網路）支持建材與工人用船直接運到高原邊緣（EV-0010）。
- **Hatnub 採石場斜坡**：2018 年發掘出一條坡度超過20%的岩切斜坡（比以往認為埃及斜坡不超過10%更陡），年代與大金字塔同時期，可能支持較陡斜坡可行（EV-0011）。

### 三、勞動力 — 確定「非奴隸」，規模有爭議

- 「奴隸建造金字塔」的流行說法**被考古學界否決**。工人的塗鴉（「胡夫的友人們」等幫派名）與工人城（Heit el-Ghurab）顯示工人以「幫（gangs）/phyles/division」組織，伙食良好（牛肉、麵包、啤酒），住在兵營式長廊（EV-0012, EV-0015）。
- **規模估計分歧很大**：希羅多德說10萬人；Lehner 的估計約幾千人到5,000名本地建造者（另加阿斯旺/圖拉工人）；DMJM 營建管理研究估計平均約14,567人、尖峰40,000人。**確切人數有爭議**（EV-0013, EV-0014）。

### 四、時間與後勤 — 規模大致共識，進度可行性有爭議

- 規模大致被接受：約 **230萬塊**，平均約 **2.5噸**，原高約 **146.6公尺**、每邊約230公尺；在胡夫約 **27年** 在位內完成，意味著平均約每 **2–3分鐘** 要放置一塊（EV-0016）。
- 材料來源：核心用吉薩本地石灰岩（南方約500公尺的採石場）、覆面用圖拉白石灰岩（約10–20公里外、跨尼羅河）、國王廳花崗岩來自約1000公里外的阿斯旺，巨石可達約60噸（EV-0017）。
- **進度可行性有爭議**：2026 年的計算模型（Integrated Edge Ramp）聲稱單一斜坡需要約49.5年（太慢），只有多斜坡策略才能在20–27年內完成（EV-0018）。但這**是模型推估，不是直接證據**（EV-0018）。

### 五、已知 vs 未知 vs 爭議

| 面向 | 狀態 |
|---|---|
| 建材經水路運到現場 | **已知／共識**（EV-0007, EV-0009, EV-0010） |
| 工人非奴隸、伙食良好、義務勞役 | **已知／共識**（EV-0012, EV-0015） |
| 金字塔規模（約230萬塊、2.5噸、146.6m） | **大致共識**（EV-0016） |
| 勞動力確切人數 | **爭議**（5,000–40,000，EV-0013, EV-0014） |
| 石塊如何「抬升到高度」 | **未知／激烈爭議**（EV-0001, EV-0002, EV-0005, EV-0008） |
| 非斜坡替代方案（滑輪配重、水力升降） | **少數、非共識假說**（EV-0002, EV-0011） |

### 未解決的爭議／缺口
- **低嚴重度**：胡夫在位年限的紀年差異（約27年 vs 約23年）——對本問題（方法/勞動/運輸）不構成負擔。
- **低嚴重度**：勞動力人數各來源相差大——已如實呈報為「規模有爭議」，非矛盾。
- 非斜坡替代方案（滑輪配重 2025、水力升降 2024）為少數假說，未進入共識——已在報告中標示為「非共識」。

### 整體信心
**中—高（medium–high）**。核心主張（水路運輸、工人非奴隸、抬升方法未知）有多個高信心主要來源（Merer 日記、2024 阿赫拉馬特研究、Lehner 的工人城發掘）支持。主要的信心限制在於「抬升方法」本質上仍是未解的爭議，且部分進度數據來自計算模型而非直接證據。

### 對問題的總結
我們**實際知道**：建材經由尼羅河與失落支流用水路運到現場（有日記與考古證據）；工人是大量、伙食良好、義務勞役的埃及人，**不是奴隸**；金字塔規模約230萬塊、平均2.5噸。我們**不知道、且仍在激烈爭議**的是：石塊究竟如何被「抬升」到金字塔的高度——斜坡+槓桿是最可能但未被證實的解釋，目前**尚無定論**。
