# Run Plan — Hypnosis: Altered State vs. Social Compliance (CONTROL condition)

## Original question
催眠到底是一個真實的意識狀態改變（altered state of consciousness / trance），還是只是社會順從和角色扮演（social compliance / role-playing）？2023-2025 的科學證據到底怎麼說？

## Grounding decision (from shared initial plan)
- Domain: hypnosis research — cognitive neuroscience, clinical psychology, philosophy of mind.
- "狀態改變" (altered state / trance) = state theory (Hilgard's neodissociation, dissociated-control theory): hypnosis involves a real change in consciousness / cognitive architecture.
- "社會順從" (social compliance / role-playing) = non-state theory (Spanos, Wagstaff, Kirsch's response set theory): explained by social-cognitive factors, expectations, compliance, without a special state.
- "科學證據" = neuroimaging (fMRI, EEG, fNIRS, TMS), behavioral studies, suggestibility scales, meta-analyses.
- Goal: establish where evidence is strong, contested, or absent — not what either side claims.

## Decomposition (sub-questions)
1. State theory evidence (neuroimaging markers, dissociation, automaticity)
2. Non-state theory evidence (expectancy, context effects, no unique physiological signature)
3. 2023-2025 neuroimaging findings — is there a reliable "hypnosis signature"?
4. Synthesis / hybrid / predictive coding accounts
5. What's resolved vs contested

## Worker assignments (cycle 1)
- Worker 1 (retrieval): SQ1 state theory evidence
- Worker 2 (retrieval): SQ2 non-state theory evidence
- Worker 3 (retrieval): SQ3 2023-2025 neuroimaging
