# Plan — Current condition (7 operators + closure-saturation stop)

## Original question
催眠到底是一個真實的意識狀態改變（altered state of consciousness / trance），還是只是社會順從和角色扮演（social compliance / role-playing）？2023-2025 的科學證據到底怎麼說？

## Grounding decision (from initial-plan.md, used as-is)
- Domain: hypnosis research — cognitive neuroscience, clinical psychology, philosophy of mind.
- "狀態改變" / altered state / trance = STATE theory (Hilgard neodissociation, dissociated-control theory): hypnosis involves a real change in consciousness / cognitive architecture.
- "社會順從" / social compliance / role-playing = NON-STATE theory (Spanos, Wagstaff, Kirsch response set theory): explained by social-cognitive factors, expectations, compliance, no special state needed.
- "科學證據" = neuroimaging (fMRI, EEG, fNIRS, TMS), behavioral studies, suggestibility scales, meta-analyses.
- The question asks what the EVIDENCE shows — not what either side claims. Establish strong / contested / absent.

## Decomposition (sub-questions)
- SQ1: State theory — what evidence supports a real altered state (neuroimaging markers, dissociation, automaticity)?
- SQ2: Non-state theory — what evidence supports sociocognitive / response-set / expectancy accounts (expectancy effects, context, no unique physiological signature)?
- SQ3: 2023-2025 neuroimaging — is there a reliable "hypnosis signature" in the brain, or is it idiosyncratic / heterogeneous?
- SQ4: Synthesis / hybrid / predictive coding accounts (Oakley, predictive coding) — what does the evidence say?
- SQ5: What is genuinely resolved vs contested; where do researchers disagree about what the data means?

## Worker assignments (cycle 1)
- W1 retrieval: SQ1 (state theory evidence)
- W2 retrieval: SQ2 (non-state / sociocognitive evidence)
- W3 retrieval: SQ3 (2023-2025 neuroimaging)
- W4 retrieval: SQ4 (synthesis / predictive coding)
- W5 reasoning: SQ5 (resolved vs contested)

## Verification criteria
- Each claim cites specific EV ids.
- Distinguish established vs contested vs gap.
- For any claim for one side, check what the other side says about the same evidence.

## Stop-condition budget (CURRENT skill — closure saturation + 7 operators)
- Hard ceilings: max 4 cycles, 400 EV, no-rework after 2 consecutive disputed cycles, diminishing-returns on NEW sub-questions.
- Stop = operators produce no genuinely new sub-questions OR ceilings hit.
- Failed search = EV of type claim (evidence of absence); change strategy.
- Permanent dispute (guard 3) = redirect to "why do sources disagree?"
