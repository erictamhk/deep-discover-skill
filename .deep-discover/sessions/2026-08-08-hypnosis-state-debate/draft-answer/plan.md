# Run Plan — Draft-Answer Condition

## Original question
催眠到底是一個真實的意識狀態改變（altered state of consciousness / trance），還是只是社會順從和角色扮演（social compliance / role-playing）？2023-2025 的科學證據到底怎麼說？

## Grounding decision (from shared initial plan)
- Domain: hypnosis research — cognitive neuroscience, clinical psychology, philosophy of mind.
- "狀態改變" (altered state / trance) = state theory (Hilgard neodissociation, dissociated-control theory): hypnosis involves a real change in consciousness / cognitive architecture.
- "社會順從" (social compliance / role-playing) = non-state theory (Spanos, Wagstaff, Kirsch response set theory): hypnosis explained by social-cognitive factors, expectations, compliance, without needing a special state.
- "科學證據" = neuroimaging (fMRI, EEG, fNIRS, TMS), behavioral studies, suggestibility scales, meta-analyses.
- Question asks what the evidence actually shows — not what either "side" claims. Establish where evidence is strong, contested, or absent.

## Initial decomposition (sub-questions)
1. SQ1 — State theory evidence: what supports a real altered state (neuroimaging markers, dissociation, automaticity)?
2. SQ2 — Non-state theory evidence: social-cognitive / response set / sociocognitive; expectancy effects, context effects, no unique physiological signature.
3. SQ3 — 2023-2025 neuroimaging findings: is there a reliable "hypnosis signature" in the brain, or idiosyncratic/heterogeneous?
4. SQ4 — Synthesis/hybrid/predictive coding accounts (Oakley hybrid, predictive coding) and what evidence says.
5. SQ5 — What is genuinely resolved vs established? Where do researchers disagree about what the data means?

## Worker assignments (cycle 1)
- W1 (retrieval): SQ1 — state theory evidence
- W2 (retrieval): SQ2 — non-state theory evidence
- W3 (retrieval): SQ3 — 2023-2025 neuroimaging
- W4 (retrieval): SQ4 — synthesis / hybrid / predictive coding
- W5 (reasoning): SQ5 — resolved vs contested

## Verification criteria
- Each claim cites specific EV ids.
- Claims about "what the evidence shows" distinguish established findings vs contested interpretations vs genuine gaps.
- Two-sided debate: every claim for one side checked against what the other side says about the same evidence.

## Operators (step 5) — apply ALL each cycle
Seven generative operators (Negation, Pairwise conflict, Implication, Provenance, Absence, Boundary, Analogy) PLUS the draft-answer operator (8th):
- Write 5-10 sentence draft answer to assessments/draft-answer-round-N.md
- Tag each assertion [BACKED] / [INFERRED] / [UNBACKED]
- Every [INFERRED] and [UNBACKED] = new sub-question

## Stop condition (step 6 + draft-answer clause)
Closure saturation BUT NOT saturated if draft answer contains any [UNBACKED] assertion.
Hard ceilings: max 4 cycles, 400 EV.
